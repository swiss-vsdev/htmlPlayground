1. Fondations & Axiomes

Vocabulaire de base

  • Univers \(\Omega\) : l'ensemble de tous les résultats possibles.
  • Événement \(A\) : un sous-ensemble de \(\Omega\) (\(A \subseteq \Omega\)).
  • Réalisation : un élément \(\omega \in \Omega\) effectivement obtenu.

Opérations sur les événements

  • Union \(A \cup B\) — « A ou B » (réalisé si au moins l'un des deux l'est).
  • Intersection \(A \cap B\) — « A et B » (réalisé si les deux le sont).
  • Complément \(A^c\) — « non A » (réalisé si A ne l'est pas).

Axiomes de Kolmogorov

Une probabilité \(P\) associe à chaque événement \(A\) un réel dans \([0, 1]\), tel que :

  1. \(0 \leq P(A) \leq 1\)
  2. \(P(\Omega) = 1\)
  3. Si \(A \cap B = \emptyset\), alors \(P(A \cup B) = P(A) + P(B)\)

💡 Propriété fondamentale

\[P(A^c) = 1 - P(A)\]

C'est la base de tout raisonnement « au moins un » : on calcule souvent plus facilement le complément.

2. Probabilités conditionnelles

Probabilité conditionnelle

La probabilité de \(B\) sachant \(A\) :

\[P(B \mid A) = \frac{P(A \cap B)}{P(A)}\]

Valable uniquement si \(P(A) > 0\).

Indépendance

Deux événements \(A\) et \(B\) sont indépendants si :

\[P(A \cap B) = P(A) \times P(B)\]

Ce qui équivaut à \(P(B \mid A) = P(B)\) : savoir que \(A\) s'est produit ne change rien à la probabilité de \(B\).

Formule des probabilités totales

Si \(B_1, B_2, \dots, B_n\) forment une partition de \(\Omega\) :

\[P(A) = \sum_{i=1}^{n} P(A \mid B_i) \, P(B_i)\]

C'est la formule qu'on utilise quand on « suit les chemins » d'un arbre pondéré.

Théorème de Bayes

Pour « remonter » un arbre de probabilité :

\[P(B \mid A) = \frac{P(A \mid B) \, P(B)}{P(A)}\]

Utilisé pour les tests médicaux, la localisation de pannes, etc.

3. Variables aléatoires

Espérance et variance

  • Espérance \(E[X]\) : moyenne théorique pondérée par les probabilités.
  • Variance \(\mathrm{Var}(X)\) : dispersion autour de l'espérance.
  • Écart-type \(\sigma = \sqrt{\mathrm{Var}(X)}\) : même unité que \(X\).
\[E[X] = \sum_i x_i \, p_i \qquad \mathrm{Var}(X) = E[X^2] - (E[X])^2\]

Propriétés à connaître par cœur

\[E[aX + b] = aE[X] + b\] \[\mathrm{Var}(aX + b) = a^2 \, \mathrm{Var}(X)\] \[\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\,\mathrm{Cov}(X, Y)\]

Variables continues

  • \(P(X = c) = 0\) pour toute valeur \(c\) (probabilité ponctuelle nulle).
  • On calcule sur des intervalles : \(P(a \leq X \leq b) = F(b) - F(a)\).
  • La densité \(f(x)\) est la dérivée de la fonction de répartition \(F(x)\).
  • \(\int_{-\infty}^{+\infty} f(x)\,dx = 1\).

4. Lois de probabilité

Loi de Bernoulli \(\mathcal{B}(1, p)\)

  • Une seule épreuve, deux issues (succès / échec).
  • \(P(X=1) = p\) et \(P(X=0) = 1-p\).
  • \(E[X] = p\), \(\mathrm{Var}(X) = p(1-p)\).

Loi binomiale \(\mathcal{B}(n, p)\)

Conditions : \(n\) répétitions identiques et indépendantes, \(p\) constant.

\[P(X = k) = \binom{n}{k} \, p^k \, (1-p)^{n-k}\]

Espérance : \(E[X] = np\)  •  Variance : \(\mathrm{Var}(X) = np(1-p)\).

\[P(X \ge k) = 1 - P(X \le k-1)\]

Loi géométrique \(\mathcal{G}(p)\) ⚠️ piège d'examen

Modélise le nombre d'échecs avant le premier succès.

\[P(X = k) = (1-p)^k \, p \qquad k = 0, 1, 2, \dots\]

Espérance (échecs) : \(E[X] = \dfrac{1-p}{p}\)  •  Variance : \(\mathrm{Var}(X) = \dfrac{1-p}{p^2}\).

⚠️ Attention : si on demande le nombre moyen de tests (ou d'essais), il faut ajouter 1 : \(E[\text{tests}] = \dfrac{1}{p}\).

Loi de Poisson \(\mathcal{P}(\lambda)\)

Modélise le comptage d'événements rares et indépendants sur une durée / un espace.

\[P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}\]

Espérance : \(E[X] = \lambda\)  •  Variance : \(\mathrm{Var}(X) = \lambda\).

8. Pièges classiques d'examen

⚠️ Géométrique vs Binomiale
La binomiale compte le nombre de succès sur \(n\) essais fixés à l'avance. La géométrique attend le premier succès (nombre d'essais aléatoire). Lire attentivement l'énoncé.
⚠️ « Au moins un… »
Utiliser le complément : \(P(\text{au moins un}) = 1 - P(\text{aucun})\). Ex. : au moins une sauvegarde réussit sur 10 → \(1 - (1-p)^{10}\).
⚠️ Espérance de la géométrique
\(E[X] = (1-p)/p\) si \(X\) = nombre d'échecs. Si on demande le nombre moyen de tests, ajouter 1 : \(E[\text{tests}] = 1/p\).
⚠️ Indépendance
Ne pas confondre \(P(A \cap B) = P(A) P(B)\) (indépendance) avec \(P(A \cap B) = 0\) (incompatibilité). Deux événements incompatibles ne sont pas indépendants (sauf si l'un est de probabilité nulle).
⚠️ Variable continue
\(P(X = c) = 0\). Ne jamais écrire \(P(X \le c) = P(X < c) + P(X = c)\) en continu : les deux premières sont égales.
⚠️ Formule de Bayes
Bien identifier \(P(A \mid B)\) (ce qu'on cherche) et \(P(B \mid A)\) (ce qu'on connaît). Souvent on inverse sans s'en rendre compte.
