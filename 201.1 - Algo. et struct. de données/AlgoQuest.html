🔢Compter les opérations

La complexité = combien d'opérations élémentaires fait ton algo.

⚡ TL;DR
On compte les opérations, on jette les constantes, on garde le terme dominant. O(1) < O(log n) < O(n) < O(n²) < O(2ⁿ).

1Pourquoi compter ?

Le temps réel dépend du CPU, du langage... pas équitable. On compte donc les opérations élémentaires (+, -, ×, comparaison, affectation).

Complexité ≈ nombre d'opérations élémentaires = f(N)

Pourquoi ? Quand N grandit, le terme dominant écrase tout.

🧙Turing, P vs NP

Les fondations théoriques de l'informatique.

⚡ TL;DR
P = facile à résoudre. NP = facile à vérifier. P = NP ? Personne sait, 1M$ à la clé.

🖥️ Machine de Turing (1936)

Ruban infini + tête lecture/écriture + états + instructions. Naissance de l'informatique théorique avant les ordinateurs.

Une machine universelle peut simuler n'importe quelle autre → fondement de l'ordinateur programmable.
